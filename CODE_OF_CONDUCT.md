# Code of Conduct

We want this project to be a respectful place for everyone.

- Be kind and assume good intent. Criticize code and ideas, not people.
- No harassment, discrimination or personal attacks.
- Do not publish other people's private information.

Maintainers may remove comments, issues or pull requests that break these rules and may block repeat offenders.

This is a short version in the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report problems to stefan@jacomeit.de.
