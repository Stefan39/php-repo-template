# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this repository.
If that is not available, write to stefan@jacomeit.de.

Please include the affected version, steps to reproduce and the impact you see. You will get a first reply within 7 days.

## Supported versions

Only the latest released minor version receives security fixes.
